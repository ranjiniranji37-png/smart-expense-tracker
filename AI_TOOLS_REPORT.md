## 5. Limitations of AI Tools
- They can give incorrect answers, so output must always be checked and tested
- They may not know the latest information
- Sensitive or personal data should not be shared with them
- Copying without understanding does not build real skills

## 6. Best Practices I Follow
1. Write clear and specific prompts
2. Test every piece of AI-generated code myself
3. Understand the code before submitting it
4. Use AI to learn faster, not to replace learning

## 7. Conclusion
